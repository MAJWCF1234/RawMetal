# RawMetal v0.5.4 - Square fixture light shafts

Ceiling-lamp fog shafts now begin across the 0.8 m square luminous fixture and widen gently downward. This removes the tiny point-source cone beneath rectangular lamps. The Vulkan ray-marched volume and software fallback use matching proportions.

An upward-looking fixture inspection view was added for visual regression checks. The release build, Vulkan smoke test, renderer test, and performance test passed. RawMetal.exe remains below the 19 MB release limit.

Download RawMetal.exe directly or extract RawMetal.zip; the ZIP contains the same single executable with embedded assets.
