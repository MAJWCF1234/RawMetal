# Save format

A save is text: a header line `RAWMETAL_SAVE <version> <checksum>`, then the archive written by `Game::archiveSave` (src/game/Saves.cpp). The current version is `Game::SaveVersion` (src/game/Game.h).

## Rules
- **Older saves load.** Every field added since is read only when `version>=N`, and falls back to a safe default otherwise.
- **Newer saves are refused.** A build refuses a save whose version is above its own and says why. Bump the version whenever an older build would misread a new save, even if no field changed (version 26).
- **The map wins over the save for what was authored.** On load, the saved props, creatures and doors are matched against today's authored map by model and home:
  - an authored prop the save does not carry comes back where it was put;
  - a saved prop the map no longer authors is dropped;
  - chunks the save never carried are loaded fresh.
- **Writing an older version is for tests only** (`archiveSave(writer, N)`). The writer leaves out what that version could not hold, such as physics props before version 17.
- **Bounds.** Every count and value is checked on load. A bad one refuses the save with the reason, rather than loading a broken game. Lists hold at most 1024 entries.

## Map format, for the same change
Custom maps (`.rmc`) are unchanged for existing content. `FIXTURE` records for office, wooden and boardroom chairs standing on a floor (base 0) become loose props when the map loads. The optional 14th field `anchored` set to 1 keeps a chair fixed. The record reference is `custom maps/GUIDE.html`, generated by `tools/campaign/make_custom_map_guide.py`. The Campaign Builder reads its record fields from that file, so the new field is editable there too.
