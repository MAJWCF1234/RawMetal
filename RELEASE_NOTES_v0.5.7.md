# RawMetal v0.5.7 - Ashfall Coast

Ashfall now extends east into three connected coastal chunks. A walkable rock-and-sand shelf slopes through the shoreline into terrain beneath the sea. Coastal water, sky, and atmosphere give the new area a brighter comparison point while the original Ashfall wasteland stays intact. Existing Ashfall chunk IDs and saves remain compatible.

Type `map coast` in the console to jump to the middle coastal chunk, then walk east to the water. The area can also be reached from Ashfall's former eastern edge. `--coast-inspection --vulkan` writes four comparison views for renderer checks.

The Release build, world isolation and terrain seam checks, save and console tests, Vulkan renderer test, smoke test, coastal render inspection, and performance test passed. The standalone EXE remains within the release size limit. `RawMetal.zip` contains the same EXE with embedded assets.
